# FolderSize Viewer Pro ⚡

Applicazione desktop nativa ad altissime prestazioni per Windows (64-bit) per analizzare ed esplorare l'intero File System e qualsiasi cartella con struttura ad albero interattiva, visualizzando all'istante la dimensione aggregata delle cartelle e consentendo l'eliminazione rapida Turbo protetta.

## ✨ Funzionalità Principali

- **Analisi Ultra-Veloce**: Scansione multi-thread di dischi e cartelle (fino a 120.000 file/secondo).
- **Dimensioni Immediate**: Nessuna necessità di entrare nelle cartelle o cliccare su Proprietà.
- **Ordinamento Intelligente**: Gli elementi più pesanti compaiono sempre in cima con barre percentuali colorate.
- **Supporto Cloud e OneDrive**: Visualizzazione corretta dello spazio occupato dai file cloud e reparse point.
- **⚡ Eliminazione Turbo Rapida**: Rimozione multi-thread parallela che bypassa le lentezze di Windows Explorer.
- **🛡️ Sistema di Protezione del Kernel**: Protezione rigorosa contro la cancellazione accidentale di file critici di Windows, System32 o radici disco.
- **🔄 Aggiornamenti Automatici**: Notifica e aggiornamento in-place automatico all'avvio o tramite pulsante dedicato.
